# Alpha-16 Archive

Before the Foundation line, Myriad Ascension was one mod (`myriad_ascension`, versions `0.1.0-alpha.1` …
`0.1.0-alpha.16`, September 2026). On 2026-10-09 it was archived for a fresh start on the Dragonblock C+ Foundation
(decision of the user: "fresh start, archive alpha-16").

## Where it is
- **Code**: git history. Last commit of the alpha line: `bcdb5d1` ("Alpha 16 cautious rebuild: weights, Qi
  progression and X quick menu"). `git checkout bcdb5d1` restores it.
- **Documents**: `archive/alpha-16/` in the repository: the old README, `docs/` (master project report, design
  specifications, alpha notes, asset guide, programming session logs, research) and the PNG validation script.

## What it contained
Mortal Genesis (sex / Yin-Yang polarity, random affinities, moral disposition), its own 7-stat block (Strength,
Vitality, Agility, Spiritual Sense, Meridian / Dantian Quality, Soul Strength), the realm hierarchy with Stage / Order
/ Rank, Tempered Body stages 1-9 with training vectors and conscious Qi gathering, G/H/R Qi controls and Burst, the
V status screen and X quick menu, the Primordialis Testudo Clan (hierarchy, offices, library, service quests),
inheritances / manuals / technique signatures, bloodlines (Primordial Tortoise), medicines and poisons, training
weights, tempered-body artifacts (armor, sword, 3D shield), empire politics.

## What happens to it
Nothing is lost: each larger system is a parked idea in the [[Idea Index]] (IDEA-001 … IDEA-010) with a pointer to
its archived design. When one is picked up it is redesigned on top of the Foundation (Qi attributes, skills,
transformations, or a new engine feature) instead of restoring the old code.
