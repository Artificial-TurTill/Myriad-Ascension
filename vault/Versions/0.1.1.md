## Changes
Requested by the user:

| Key | Function |
| --- | --- |
| V | Character menu (creation wizard if you have no character) |
| C (hold) | Raise power release |
| Shift + C | Lower power release |
| G | Transform |
| H | Back to base form |
| R | Qi Surge (Turbo) |
| X | X menu |

### Foundation
- New key layout (above); keys renamed in the controls menu.
- **Turbo** (DBC TurboMode / DashKi) as an engine feature for power types with `turbo: true`: toggle, faster run
  from the release and the new `speed` statistic, energy per second, charge twice as fast, energy regeneration
  paused, ends at 0 % release / no energy ([[Combat and Resources]]). Skill effect `dash` for later Dash-like skills.
- **X menu** back, rebuilt from alpha-16's quick menu as a generic Foundation menu with an add-on registry:
  Turbo, "Transform into", Character, Skills, Transformations, Resource HUD ([[Foundation Overview]]).
- Sheet and creation wizard show the Turbo speed in % (JRMCore "Running speed").
- HUD shows the Turbo name while it is on; the HUD can be hidden from the X menu.

### Myriad Realm
- **Qi Surge** = Qi's Turbo (name via `turbo.myriad_realm.qi`); `qi_speed` statistic (1.0 per point, DEX) and class
  speed bonuses (Spirit +10 %, Body −10 %), see [[Qi]].
- **No transformations yet** (user decision): the example form "Qi Surge" is removed, `transformations.arsn` is
  empty and ready; the engine, the G / H keys and the Transformations tab stay.

## Adaptations (deviations from Dragonblock C+ / JRMCore)
- Turbo runs only with Turbo on (DBC DashKi also ran with sprint); no flight / swoop yet.
