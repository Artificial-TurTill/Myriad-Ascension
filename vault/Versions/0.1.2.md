## Changes
User report: "The hairstyle manager was not needed to be removed." It is back, ported from Dragonblock C+
(JRMCore custom hair), see [[Races and Appearance]] → Hairstyle manager.

### Foundation
- `HairCode`: the 786-digit JRMCore hairstyle code, the six JRMCore presets, version 1 upgrade, strand geometry.
- `Appearance` stores the hairstyle code and any hair colour (was a style number + preset colour); race content
  field `hair_styles` replaced by `hair` (bool).
- Barber Menu ("Hairstyle"): custom hair / bald, quick colours, HSB colour picker, Revert, Cancel, Done.
- Five-page editor (Front, Right, Left, Back, Top) with Tier 1 / Tier 2 sliders, show / hide, reset group, repeat,
  yaw / pitch, presets (save / delete own ones), Share / Paste / Reset.
- Hair rendering on every player with a character (own texture), live preview while editing, hidden under helmets.
- Reachable from the creation wizard (Hair row), the character sheet (Hairstyle button) and the X menu (Hairstyle).
- `HairUpdatePayload`: the hairstyle can be changed at any time.
- UI fixes found in the first real-client check: Summary hair swatch overlapped its text; the X menu's hints
  overlapped the HUD (the HUD now hides while the X menu is open); the editor's repeat button moved away from the
  Yaw arrows.

### Myriad Realm
- "Qi Surge speed" shortened to "Surge speed" on the sheet (it touched the panel edge).
