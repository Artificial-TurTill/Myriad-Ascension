## Changes
### Foundation (new mod `ascension_foundation`)
- The character system of Dragonblock C+ 0.8.0.2 (its JRMCore layer) extracted and generalised into its own mod:
  [[Foundation Overview]], mapped in [[DBC+ Extraction Map]].
- Content is data: races, power types, classes, skills and transformations are read from ARSN files of the
  Foundation and of add-ons, validated when the game loads ([[Content Files]]).
- Built in: race **Human** (the only race for now) with appearance options; power type **Natural** (vanilla hearts,
  STR / DEX / CON, Melee Dmg / Defense / Health, class "Unclassed").
- Character: race, gender, appearance (skin, hair style and colour, eyes, body type, height), power type, class,
  attributes, TP, level, Body / energy / Stamina, power release, skills with capacity (DBC Mind), transformations
  with mastery, alignment ([[Stats and Attributes]], [[Skills]], [[Transformations]]).
- JRMCore damage pipeline for Body characters, TP per powered hit, regeneration ([[Combat and Resources]]).
- Creation wizard (Appearance → Power Type → Summary), character sheet with "+" and UC multiplier, Skills tab,
  Transformations tab, HUD; keys V / G (Shift+G) / R / Z.
- `/foundation` operator commands.
- All Dragonblock C+ items, blocks, worlds, NPCs, sagas, Ki techniques and its five other races are **not** part of
  the Foundation.

### Myriad Realm (new mod `myriad_realm`, requires the Foundation)
- Power type **Qi**: its own system (not DBC Ki), six attributes STR / DEX / CON / WIL / MND / SPI, **every attribute
  starts at 1**, Body is the only life ([[Qi]]).
- Classes Martial Cultivator / Spirit Cultivator / Body Cultivator (the DBC class concept).
- Skills Qi Meditation, Qi Condensation, Endurance.
- Example transformation Qi Surge (to be replaced by the first real Myriad Realm form).
