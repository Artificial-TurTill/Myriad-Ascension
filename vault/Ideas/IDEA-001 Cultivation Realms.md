# IDEA-001 System: Cultivation Realms

Parked from the archived single-mod alpha ([[Alpha-16 Archive]]). Not implemented in the Foundation line yet; the
full design is in `archive/alpha-16/docs/design/ (realm-hierarchy.md, cultivation-progression-power.md, martial-peak-progression-adaptation.md)`.

## Summary
Mortal → Tempered Body (9 stages) → Initial Element → … up to multiverse levels, each with Stage / Order / Rank subdivisions; realms change capabilities, not only numbers.

## How it could fit now
A Myriad Realm system on top of Qi: a realm could gate transformations (field `previous`/`skill` today, a realm requirement later = engine need), raise attribute limits, and unlock skills. Engine need: a generic "progression track" in the Foundation that add-ons can define (realm list + requirements).
