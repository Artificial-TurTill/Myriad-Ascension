# Programming Session Logs

Programming work on Myriad Ascension is accompanied by a session log under this directory.

## Logging rule

For each programming session:

- create the log when the session begins,
- record the user's requested behavior and constraints,
- append implementation decisions as they are made,
- record files/systems changed,
- record validation, build, CI and runtime results,
- distinguish completed work from planned or unverified work,
- do not rewrite UI/art direction that the user has explicitly reserved for manual editing unless requested.

Session logs are development records, not substitutes for release notes. User-facing release changes still belong in `docs/ALPHA.md`.
